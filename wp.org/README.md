# WordPress.org listing assets

Files in this folder are uploaded to the plugin's `assets/` directory on
WordPress.org SVN. They are NOT shipped inside the plugin zip (see `.distignore`).

| File | Size | Notes |
|------|------|-------|
| `icon-128x128.png` | 128×128 | Plugin icon (small) |
| `icon-256x256.png` | 256×256 | Plugin icon (retina) |
| `icon.svg` | any | Optional vector icon, preferred by wp.org |
| `banner-772x250.png` | 772×250 | Listing banner |
| `banner-1544x500.png` | 1544×500 | Listing banner (retina) |
| `screenshot-1.png` … `screenshot-N.png` | ~1280×800 | Numbered to match the `== Screenshots ==` list in `readme.txt` |

Also accepted: `.jpg` for banners/screenshots. Keep every file under 1 MB.

## Source artwork in this folder

Generated by `build-assets.py` (fonts in `src-fonts/`, dark logo in `src-logo-dark.svg`):

- `icon-aiswitch.svg` (256x256) - the AI sparkle above two provider rows with toggles.
- `banner-aiswitch.svg` (1544x500) - matching banner, "Connect any AI to WordPress."

Export the PNG sizes above from these. Edit copy or colours in
`build-assets.py` and re-run `python3 build-assets.py`.

### Animated pair (aiswitch)

- `icon-aiswitch-animated.svg` - looping tile: sparkle breathes and twinkles, top toggle flips.
- `banner-aiswitch-animated.svg` - same tile loop plus a one-shot entrance for the pill,
  headline lines, orange rule and subline (about 1.3 s). Both freeze under
  `prefers-reduced-motion` and their final frame matches the static files.
  Use them on the website / GitHub README; wp.org itself only accepts PNG/JPG.
